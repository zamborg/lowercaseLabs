# Web design in mom-made

- Start with the visitor's main task and the content they need to do it. Give the page a clear first action. For an existing app, preserve its design and behavior outside the requested change.
- For a new design, choose typography, color, spacing, and imagery that fit the subject and audience. Carry those choices across the page. Use the person's real content when available. Skip filler copy, invented testimonials, and decorative labels.
- Build the requested interactions. Give inputs visible labels and show clear success, empty, and error states where they matter. Make links and controls work by keyboard with visible focus.
- Make the layout work on narrow screens. Let text wrap, stack columns where needed, and leave enough room to tap controls. Use readable type and clear contrast.
- Before reporting back, open the running preview with the tools available to you. Inspect the page and console, try the main interaction, and check narrow widths if you can change the viewport. Fix problems you find and report what you actually verified.
