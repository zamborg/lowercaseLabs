# Brief 13: v1 UI

**Executor:** Claude (Sonnet). **Depends on:** 10, 12. Write each flow alongside its screen, not after.

## Goal

The three-tab app in [VISION.md](../VISION.md#v1-what-you-see). Black, minimal and fast. The capture screen sets the tone. Everything else is quiet and gets out of the way.

## Screens

### Tab bar

Three tabs: Capture (default), Void, Social. On Capture, the tab bar must not compete with the circle. Keep it dark and low-contrast.

### Capture

- Circle **reacts to input level** while listening. Use RMS from the tap, smoothed, throttled to display rate. No work on the render thread beyond computing one float.
- **Hold to record.** The circle grows on the same frame as the touch (already done; keep it).
- **Slide up to lock** (D6). Past a threshold, show a lock state. Release keeps recording. Tap to stop.
- Live transcript above the circle.
- **Visibility control** for this message: a small private/shared toggle near the circle, defaulting per D5. It applies to the message being captured and can be changed after release, until you leave the screen.
- After release: title and tag dots fade in when enrichment lands.
- Remove the current top-bar buttons and sheets. Tabs replace them.

### Void

- List, newest first. Each row shows the title (or "Untitled" in a dimmed style while enrichment is pending), tag dots, relative date, duration, and a shared indicator.
- Swipe to delete (F8).
- Tap a row to open the **card**:
  - Playback: play/pause, scrubber, elapsed and total time. Use `AVAudioPlayer`.
  - Editable title, editable transcript, and tag editing by tapping the four quadrant dots, with a maximum of two. Edits set the matching `...SetByUser` flags.
  - Private/shared toggle (calls `Pipeline.setVisibility`).
  - Delete.

### Social

- A grid: rows are friends, columns are the last 14 days, cells hold that day's dots (colored by quadrant, several per day allowed).
- Tap a cell to see tags and times only.
- An **Invite** button (existing `InviteSheet`).
- Empty state when there are no friends: one line plus the invite button.
- Until rig C exists, drive it from `-seed` friend data. Never fake data in a normal launch.

## Flows to write with this brief

F3 (lock), F4 (edit, UI half), F5 (playback), F8 (delete, full), plus a screenshot pass of every screen with seeded data, in both the empty and populated states.
