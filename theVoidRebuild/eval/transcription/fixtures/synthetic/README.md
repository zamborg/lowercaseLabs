# SYNTHETIC smoke-test clips

These three clips are generated by macOS `/usr/bin/say`, not human recordings.
They exercise file decoding, final-result collection, scoring, and report output.
They cannot establish accuracy on the owner's future recordings, accents,
background noise, hesitations, microphone quality, or iPhone performance.

`reference.jsonl` contains the exact text supplied to `say`, with
`"source":"synthetic"` on every entry. `generation.json` records voice, speaking
rate, host OS, and generation time. The default voice is Samantha, with rates
145, 175, and 205 words per minute. Audio uses `say`'s default AIFF format.

From `eval/transcription/`, regenerate all fixtures with:

```sh
python3 scripts/make_synthetic.py
```

If Samantha is unavailable, inspect `/usr/bin/say -v '?'` and pass an installed
English voice with `--voice <name>`. Regeneration overwrites these fixtures.
