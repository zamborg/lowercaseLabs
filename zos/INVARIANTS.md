# ZOS Invariants

Architectural and security invariants enforced by automated tests. Every change must keep all invariants green.

| # | Invariant | Enforced by |
|---|---|---|
| 1 | **No policy or audit bypass:** every tool call (core, upstream, actuator, and module) passes through `visibility -> allowance chain -> audit` with no bypass; module tools appear in `/admin/policy`. | `tests/unit/test_policy_engine.py`, `tests/integration/test_m10a_policy.py`, `tests/integration/test_m10d_inbox_policy.py` |
| 2 | **No raw args in audit log:** `events` stores only SHA-256 canonical JSON digests (`args_digest`), never raw tool arguments or secrets. | `tests/integration/test_audit.py`, `tests/integration/test_m9c_async_approvals.py`, `tests/e2e/test_m9a_routed_mcp.py` |
| 3 | **Secret & credential isolation:** secrets live only in the AEAD vault (`credentials`) and env; modules never see client OAuth/bearer tokens, the owner `zos_admin_session` cookie, `Authorization`, or core Postgres tables. | `tests/unit/test_vault.py`, `tests/integration/test_m10b_modules.py::test_module_postgres_role_isolation_and_purge`, `tests/integration/test_m10c_ui_proxy.py::test_module_ui_proxy_end_to_end`, `tests/integration/test_m11_non_superuser.py` |
| 4 | **Signed module caller identity:** every ZOS → module `tools/call` carries HMAC-SHA256-signed `params._meta["zos/caller"]`; unsigned calls are system calls; reserved mailbox names (`owner`, `general`) are refused over MCP (`CALLER_RESERVED`). | `tests/unit/test_m10b_modules.py::test_caller_sdk_mcp_sign_and_verify`, `tests/integration/test_m10b_modules.py::test_module_lifecycle_signed_caller_and_admin_ui`, `modules/inbox/tests/test_inbox.py::test_inbox_mcp_tools_auth_privacy_and_general_read_state` |
| 5 | **Untrusted clients never escalate:** `trust_ceiling = 'untrusted'` hides external tools at visibility and clamps any `escalate` verdict to `deny`. | `tests/unit/test_policy.py`, `tests/unit/test_policy_engine.py::test_untrusted_clamp_applies_to_explicit_engine_escalate` |
| 6 | **Fail-safe policy engines:** any engine exception, timeout (`ZOS_POLICY_ENGINE_TIMEOUT_S`), or invalid verdict becomes `escalate` (or `deny` for untrusted clients). | `tests/unit/test_policy_engine.py::test_engine_timeout_and_exception_become_escalate_and_clamp_for_untrusted` |
| 7 | **Read-only policy inputs:** allowance engines receive a read-only deep copy of call arguments (`MappingProxyType` / immutable collections) and can never mutate executed args. | `tests/unit/test_policy_engine.py::test_mutating_engine_cannot_alter_executed_args` |
| 8 | **Strict core/module boundary:** core (`src/zos/`) never imports module code; modules (`modules/*/src/`) and `zos_module_sdk/` never import `zos`. | `tests/unit/test_invariants.py`, `modules/inbox/tests/test_inbox.py::test_inbox_has_zero_zos_imports` |
| 9 | **Owner visibility primitive:** every stateful module exposes an owner UI under `/admin/m/<slug>` showing all of its underlying state (including client-to-client data), and owner reads never mutate clients' own read state. | `modules/inbox/tests/test_inbox.py::test_owner_visibility_all_mailboxes_without_mutating_client_read_state` |
| 10 | **Single instance per deployment:** exactly one ZOS process may run against a database (sessions, approval waits, actuator sockets, and upstream MCP sessions live in memory); startup fails loudly via a Postgres advisory lock if a second instance is detected. | `tests/integration/test_m11_invariants.py::test_single_instance_advisory_lock_blocks_second_process` |
| 11 | **Container & DB hardening:** ZOS writes the module container spec (`Privileged=False`, `CapDrop=["ALL"]`, `no-new-privileges`, no host binds/mounts, internal `zos_modules` network, memory cap); each Postgres module gets an isolated `mod_<slug>` role with zero access to core tables; ZOS core itself runs without Postgres superuser. | `tests/unit/test_m10b_modules.py::test_docker_host_container_spec_hardening_and_networks`, `tests/integration/test_m10b_modules.py::test_module_postgres_role_isolation_and_purge`, `tests/integration/test_m11_non_superuser.py` |
| 12 | **Standalone owner auth:** `/admin*`, `/oauth/authorize`, and `/connect/*` are protected by ZOS's own passphrase, signed HttpOnly cookie, CSRF, and rate limits; Cloudflare Access is defense in depth only. | `tests/integration/test_admin.py`, `tests/integration/test_m7_hardening.py`, `tests/integration/test_m11_invariants.py::test_owner_routes_protected_without_cloudflare_access` |
