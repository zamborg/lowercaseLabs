# Purpose

Define the product invariants so engineering does not drift.

# Principles (non-negotiable)

1. Flow-state first: single-email focus, keyboard-first operations, zero UI clutter.
2. Human is supervisor: user declares intent; agent performs the email-writing.
3. Break-glass manual send: direct raw compose exists but is intentionally annoying.
4. Outcome-driven inbox: messages are treated as open loops with explicit statuses.
5. Memory by default: remember/notes is a first-class feature replacing star.
6. Reversibility: every agent action must be reversible and auditable.
7. Least autonomy by default: autonomy increases only within user-defined categories/policies.

# Definitions

- Triage action: archive / delete / snooze / remember / delegate reply / escalate.
- Loop: a tracked outcome tied to one or more emails/threads (waiting, scheduled, closed).
- Category: a grouping of emails (e.g., Recruiters) with policies and templates.
- Notes doc: a generated, structured memory document with citations to email IDs.

# Success Metrics (MVP)

- Median time to triage an email: < 6 seconds in TUI.
- Percent of replies sent via delegation (not break-glass): > 90%
- Notes recall: user can retrieve why did I star/remember this with 1 query.
